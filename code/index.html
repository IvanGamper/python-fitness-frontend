SCHRITT FÜR SCHRITT

Einen Workout-Generator mit Python coden.

Unser erstes Projekt wählt zufällig Übungen aus einer Liste aus. So entsteht mit wenigen Zeilen ein kleines Workout.

1

Übungen sammeln

Wir legen zuerst fest, welche Übungen zu welchem Fokus gehören. Ein Dictionary ist dafür praktisch: links steht der Fokus, rechts die passende Liste.

UEBUNGEN = {
    "mobility": ["Tiefe Hocke", "Cossack Squat", "World's Greatest Stretch"],
    "kraft": ["Kniebeuge", "Liegestütz", "Plank"]
}
2

Drei Übungen auswählen

Mit random.sample() nimmt Python drei unterschiedliche Übungen aus der gewählten Liste. Die Funktion gibt das fertige Workout zurück.

import random

def erstelle_workout(fokus, anzahl=3):
    passende_uebungen = UEBUNGEN[fokus]
    return random.sample(passende_uebungen, anzahl)
3

Workout ausgeben

Jetzt rufen wir die Funktion auf und zeigen jede Übung an. Beim nächsten Start kann die Reihenfolge anders sein – genau das macht es abwechslungsreich.

workout = erstelle_workout("mobility")

print("Dein heutiges Workout:")
for uebung in workout:
    print("-", uebung)
Nächster Schritt: Ergänze eigene Kategorien wie "handstand" oder "rücken". Du kannst später auch Wiederholungen, Zeiten oder Schwierigkeitsgrade hinzufügen.
